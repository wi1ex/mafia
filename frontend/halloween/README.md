# Halloween: одна папка со всем комплектом

Все дополнительные файлы темы находятся в **`frontend/halloween/`**. Для её подключения за пределами папки изменены пять ранее существовавших файлов:

- `frontend/src/pages/Home.vue`
- `frontend/src/views/Carousel.vue`
- `frontend/src/views/Header.vue`
- `frontend/src/pages/Room.vue`
- `frontend/vite.config.ts`

Отдельно, по просьбе пользователя, `frontend/src/assets/images/killPlayer.png` заменён на постоянную иллюстрацию: мафиози в федоре, убитый игрок и бирюзовый призрак. Она используется и без Halloween и остаётся после отката темы. Для Halloween в этой папке находится другая версия `killPlayer.png`. В обычном `frontend/src/assets/images/carousel-image2.png` также обновлена надпись на «1500+ уникальных пользователей»; эта правка остаётся после отката темы. Остальные исходные изображения в `frontend/src/assets/images/` сохранены.

Первые два сезонных слайда `carousel-image1.png` и `carousel-image2.png` используют прикреплённые пользователем изображения. На втором слайде надпись обновлена на «1500+ уникальных пользователей», как и в обычной версии. Повторный HTML-слой скрыт только для этих двух слайдов. Они вписываются целиком в карусель через `object-fit: contain`, поэтому края, монеты, тыква и надписи не обрезаются. Остальные слайды сохраняют прежние изображения и отдельный текстовый слой. Сезонные изменения целиком находятся в папке темы.

В комнате сезонные изображения заменяют шесть игровых статусов, сохраняя прежние условия их показа:

| Файл | Значение |
|---|---|
| `fouledPlayer.png` | Игрок удалён со стола по фолам. |
| `killPlayer.png` | Игрок убит мафией ночью. |
| `leavePlayer.png` | Игрок совершил самоубийство. |
| `lowSignal.png` | У игрока проблемы с сетью. |
| `sleepPlayer.png` | Игрок спит. |
| `votedPlayer.png` | Игрок изгнан со стола голосованием. |

Все шесть сезонных файлов находятся в этой папке; включение темы не перезаписывает постоянные PNG. Подключение работает и при прямом открытии комнаты, где общий хедер не отображается. Сопоставление причин смерти и приоритеты статусов остаются прежними.

Для пустого списка комнат используется сезонная версия `iconNoRooms`: прежний кот под сломанным зонтом с пиксельной ведьминской шляпой, пиксельной тыквой и бирюзово-оранжевыми контурами. Новые детали используют ступенчатые линии на целочисленной сетке, без плавных кривых и скруглений. Исходная SVG-иконка, её размер 220×250 и текст «Пока нет комнат...» сохраняются. Замена выполняется только в сезонном CSS; удаление темы возвращает исходный вариант без отдельных правок `Home.vue`.

Логотип с кровавыми потёками и тыквой и кнопка профиля с двумя когтями отображаются на всех страницах, использующих общий хедер, в том числе при прямом открытии этих страниц. Кнопка профиля сохраняет пользовательский фон, аватар, ник, значки, стрелку и прежнее меню; медная рамка и когти добавлены только в сезонном CSS. Кнопка создания комнаты и её украшения остаются частью главной страницы. На страницах без хедера отдельный логотип не добавляется.

При наведении мыши и фокусе с клавиатуры пальцы кнопки создания комнаты слегка стягиваются к центру, а оранжевая поверхность немного сжимается. При нажатии захват усиливается, при отпускании плавно возвращается. Область клика и текст не двигаются, недоступная кнопка не анимируется. Системная настройка `prefers-reduced-motion: reduce` отключает движение. Эффект выполнен в `theme.css` с существующим изображением пальцев; дополнительных кадров и правок компонентов нет.

Обычный `frontend/src/assets/images/carousel-image2.png` сохранён в исходном разрешении 607×494 с прозрачностью скруглённых углов. Надпись остаётся «1500+ уникальных пользователей».

## Полный откат к старому дизайну

Сначала прочитайте инструкцию: при удалении папки она тоже исчезнет.

Откат убирает Halloween-оформление. Постоянная замена `frontend/src/assets/images/killPlayer.png` и надпись «1500+ уникальных пользователей» в обычном `carousel-image2.png` в него не входят: эти изменения сохраняются.

### Простой способ: готовый патч

Выполните из корня репозитория:

```powershell
git apply --check frontend/halloween/rollback.patch
git apply frontend/halloween/rollback.patch
```

Первая команда только проверяет возможность отката. Вторая убирает подключение Halloween из пяти старых файлов. Другие части проекта она не затрагивает. Если проверка сообщает о конфликте с последующими правками, используйте ручной способ ниже.

Затем удалите **только папку `frontend/halloween/` целиком**. После этого:

```powershell
npm --prefix frontend run typecheck
npm --prefix frontend run build
```

Опубликуйте результат обычным способом.

### Ручной способ: что изменить в старых файлах

#### 1. frontend/vite.config.ts

Удалите импорт:

```ts
import halloweenThemePlugin from './halloween/vite-plugin.ts'
```

Из массива `plugins` удалите только строку:

```ts
halloweenThemePlugin(),
```

Остальные настройки оставьте.

#### 2. frontend/src/pages/Home.vue

- Верните корневой элемент к `<main class="card">`: уберите класс `home-page`.
- Удалите импорт `import { useHomeSeason } from '../../halloween/homeSeason'`.
- Удалите строку `const { seasonImage, resetHomeSeason } = useHomeSeason()`.
- Верните два изображения в блоках подписки и обратной связи к следующему виду:

```html
<img class="background-image-6" :src="imageSlide6" alt="" aria-hidden="true" />
<img class="background-image-7" :src="imageSlide7" alt="" aria-hidden="true" />
```

То есть замените `seasonImage(5, imageSlide6)` и `seasonImage(6, imageSlide7)` на `imageSlide6` и `imageSlide7`, а с этих двух тегов уберите `@error="resetHomeSeason"`.

#### 3. frontend/src/views/Carousel.vue

Удалите два импорта:

```ts
import { useHomeSeason } from '../../halloween/homeSeason'
import SeasonalSlideCopy from '../../halloween/SeasonalSlideCopy.vue'
```

Удалите строку:

```ts
const { seasonActive, seasonImage, resetHomeSeason } = useHomeSeason()
```

Верните источники пяти штатных изображений:

| Сейчас | После отката |
|---|---|
| `:src="seasonImage(0, imageSlide1)"` | `:src="imageSlide1"` |
| `:src="seasonImage(1, imageSlide2)"` | `:src="imageSlide2"` |
| `:src="seasonImage(2, imageSlide3)"` | `:src="imageSlide3"` |
| `:src="seasonImage(3, imageSlide4)"` | `:src="imageSlide4"` |
| `:src="seasonImage(4, imageSlide5)"` | `:src="imageSlide5"` |

У этих пяти изображений уберите `@error="resetHomeSeason"`.

Удалите пять строк:

```html
<SeasonalSlideCopy v-if="seasonActive" :slide="1" />
<SeasonalSlideCopy v-if="seasonActive" :slide="2" />
<SeasonalSlideCopy v-if="seasonActive" :slide="3" />
<SeasonalSlideCopy v-if="seasonActive" :slide="4" />
<SeasonalSlideCopy v-if="seasonActive" :slide="5" />
```

Остальные элементы, стили и логику карусели оставьте.

#### 4. frontend/src/views/Header.vue

Удалите импорт:

```ts
import { useHomeSeason } from '../../halloween/homeSeason'
```

Удалите отдельный вызов в начале setup:

```ts
useHomeSeason()
```

Остальную разметку и логику хедера оставьте. Сезонный логотип и тыква оформлены только в CSS папки `halloween`, поэтому после удаления подключения вернётся исходный логотип.

#### 5. frontend/src/pages/Room.vue

Удалите импорт:

```ts
import { useHomeSeason } from '../../halloween/homeSeason'
```

Удалите строку:

```ts
const { seasonPlayerImage } = useHomeSeason()
```

В обоих компонентах плиток игроков замените `:offline-avatar="seasonPlayerImage('lowSignal', iconLowSignal)"` на `:offline-avatar="iconLowSignal"`.

В функции `visOffAvatar` верните штатное изображение сна:

```ts
return gamePhase.value === 'idle' ? iconVisOff : iconSleepPlayer
```

Верните таблицу причин смерти и функцию `deadAvatar` к следующему виду:

```ts
type DeathReasonKind = 'suicide' | 'foul' | 'vote' | 'night' | string
const DEAD_ICON_BY_REASON: Record<DeathReasonKind, string> = {
  suicide: iconLeavePlayer,
  foul: iconFouledPlayer,
  vote: iconVotedPlayer,
  night: iconKillPlayer,
}
const deadAvatar = (id: string): string => {
  const reason = game.deathReason(id) as DeathReasonKind
  return DEAD_ICON_BY_REASON[reason] || iconKillPlayer
}
```

Шесть импортов PNG из `src/assets/images/` оставьте: после отката используются именно эти постоянные версии, включая обновлённый `killPlayer.png`.

#### 6. Удаление и сборка

Удалите **`frontend/halloween/` целиком**. Других дополнительных файлов или папок Halloween в исходниках нет.

Выполните:

```powershell
npm --prefix frontend run typecheck
npm --prefix frontend run build
```

После обычной публикации вернётся оформление без Halloween, с обновлённым постоянным `killPlayer.png` и надписью «1500+ уникальных пользователей» в обычном втором слайде. Без перечисленных правок удаление исходной папки вызовет ошибку импорта при следующей сборке, поэтому для полного отката нужны оба действия.

## Быстрое отключение на уже работающем сервере

При сборке публикуются семь фоновых PNG, пять декоративных ресурсов (два PNG и три SVG), шесть PNG игровых статусов, `manifest.json` и `theme.css` по прежнему адресу `/seasonal/halloween/`: всего 20 файлов, включая 18 изображений. Инструкция, патч, тесты, промпты и исходные TS-файлы туда не копируются.

Удаление опубликованной папки `seasonal/halloween/` и обновление страницы возвращают штатное оформление без пересборки; новая постоянная версия `killPlayer.png` и надпись «1500+ уникальных пользователей» в обычном втором слайде сохраняются. В текущем контейнере Nginx папка находится в `/usr/share/nginx/html/seasonal/halloween/`.

Это временное отключение до следующего развёртывания из прежнего образа. Для постоянного полного отката выполните раздел выше. Удаление только локальной папки не меняет уже запущенный контейнер.

## Проверки и обновление

Из корня репозитория:

```powershell
node frontend/halloween/check-home-season.mjs
npm --prefix frontend run typecheck
npm --prefix frontend run build
```

При замене картинок или CSS меняйте `revision` в `manifest.json`. Манифест содержит строгую таблицу `playerImages` с шестью именами игровых статусов. Отсутствие манифеста отключает тему даже при наличии старых картинок в кеше. Все семь фоновых изображений, пять декоративных ресурсов, шесть игровых статусов и CSS должны загрузиться успешно, прежде чем оформление включится. Если один из них недоступен, возвращаются штатные изображения и стили; при сбросе также удаляются CSS-переменные украшений. Проверка загрузчика охватывает каждый из шести недоступных статусов, некорректную таблицу `playerImages`, сброс темы и удалённую опубликованную папку.

## Варианты кнопки профиля

- `profile-options.html` — локальное сравнение трёх вариантов, длинного ника и пользовательских фонов кнопки.
- `profile-concept-copper.png` — «Медная рамка».
- `profile-concept-web.png` — «Паутинка».
- `profile-concept-claws.png` — «Когти».
- `profile-concepts-prompts.md` — промпты встроенного image_gen.

В действующем хедере применён вариант «Когти»: два небольших когтя по верхним краям, тонкая медная рамка, кольцо вокруг аватара и мягкая подсветка при наведении, фокусе и открытом меню. Для когтей повторно используется `button-fingers.png`; новых публичных ресурсов и новых правок старых компонентов не требуется. Превью остальных вариантов сохраняются в этой же папке и не публикуются вместе с темой. Полный откат выполняется по инструкции выше без дополнительных действий.
